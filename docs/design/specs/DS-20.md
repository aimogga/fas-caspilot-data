Source docs: `docs/design/PLAN_DS-20_DS-21.md` (George, 2026-10-16; on PR #286, not on main yet: scope, audit and the four design decisions are taken from there and not re-opened); `docs/DESIGN.md` Part 2 need-map rules 2, 4, 5, 6, 8 and general rules 1, 2, 5, 6; `docs/DESIGN_WORKFLOW.md`; `docs/design/targets/visual-direction.md` (County need map); `.claude/skills/design-polish/references/*`; precedents DS-06 (map, panel), DS-11a (explain layer), DS-11b (map hover card, ranked list, legend `Hint`s), DS-19 (spec format).

## Purpose and users
The page answers one question: where is the need greatest? A board member should see the answer before touching anything; a staff member should be able to pick any county and see why it ranks where it does; anyone comparing exact numbers uses the table. Today everything is shown at once at the same weight (plan, "What is wrong today"), so the answer is buried.

| Role | Gets (after a, b, c) |
|---|---|
| staff, admin | the map with its legend directly underneath, the five highest-need counties beside it, a short county panel on a pick, a nine-column table |
| board_viewer | the same page, same data, `BOARD` eyebrow (`NeedMapQuery.eyebrow`) |

## Decisions (designer defaults, inside George's plan)
1. Swatches carry no visible words; their names and hints carry band and count. The ramp reads as one bar with "Lower need … Higher need" under its ends, which is the convention for a sequential legend and fits 375 without wrapping.
2. The map is left-aligned in its column from 1024 (`preserveAspectRatio`), so the legend sits flush under it instead of under empty space.
3. With `?fas=1` the heading becomes `Highest need among FAS counties` so the list is never mistaken for the statewide top five.
4. The list's numbers explain themselves through one `ExplainLayer` (same attributes as the table cells), not one Radix root per number (polish bar X5); the name is the link so the 44 px row target never nests a button in a link.
5. `CountyPanel` imports `Swatch`/`fillFor` from `NeedMap.tsx` (a render-time cycle, harmless); moving the swatch to its own file is left for b to avoid churn here.

## Open questions
1. Below 768 the table is replaced by the ranked list, so "on the map or in the table" is slightly off at 375 (the existing `SELECT_PROMPT` has the same wording). Keep, or say "map or list" below 768?
2. P1 (codes beside words): the footer and source lines still say "Census SAHIE / SAIPE / ACS 5-year" without the plain names. Out of a's scope; b's group headings ("Health coverage — Census SAHIE") are the natural fix.
3. Shots are local synthetic renders; the supervisor may want preview shots (`pnpm shots --id DS-20a`) after merge.

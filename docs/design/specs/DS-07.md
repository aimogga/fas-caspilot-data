# DS-07 — Team dashboard
Source docs: `fas-screen-plan.md` §4 P1-1 (Team dashboard / F-401), §1.2 nav, §3 trust patterns; `docs/PRD.md` §C3 (M1–M6, O1 definitions; team dashboard; pipeline statuses); `fas-product-inventory.md` F-401, screen #12; `design-system-v1.md` (KPI card, table, chart, badges); mockup `docs/design/mockups/p1-team-dashboard.png`; feature list F-401 ("Six metrics + outcomes with trends and filters"; "Data freshness and grant pipeline widgets"; "Every number shows its as-of date"; test `e2e: team-dashboard.spec.ts screenshot`).
**Depends on:** DS-05 (freshness status helper + chip), F-304 (M1–M6 views), F-306 (suppression in shared views), F-305 (O1) for the outcomes card, `pipeline_status` readable for the pipeline widget. Each card ships behind its own data: a card whose view doesn't exist yet renders the "not available yet" state, never fake numbers. **Budget:** ≤ 400 hand-written lines per PR (D-012). **Mockup:** `p1-team-dashboard.png` (1440).

## Purpose and users
One screen where staff see whether FAS help is working, in numbers ready to cite: the headline M1, the other five metrics, outcomes, data freshness and the grant pipeline, each with source and as-of.

| Role | Gets |
|---|---|
| staff | Full dashboard, filters, links into metric detail (when built) |
| admin | Same as staff |
| board_viewer | **403** (DS-04 card, area "Team dashboard"). Board uses the board dashboard (F-402). |

## Scope
- Route `/dashboard`, `['admin','staff']`. Unhide nav "Team dashboard" (Workspace) for staff and admin. Crumb `Team dashboard`.
- Filters (URL params, server-rendered): `period` (quarter, default latest complete quarter, e.g. `2026-Q3`; approved), `county` (fips or `all`), `referral` (referral source or `all`), `compare` (`prior` = prior quarter, default on; approved).
- Lead metric: M1 (approved). M3 never-started window: 60 days (approved; configurable).
- Cards: M1 headline, M2, M3, M5, M4 table, M6, O1, Data freshness widget, Grant pipeline widget.
- All FAS numbers come from suppressed shared views (F-306). The UI never computes suppression itself; it renders what the view marks.
- Out of scope: metric detail pages, Export packet (F-403; button hidden until the route exists), editing pipeline, charts beyond the sparkline/trend line per card.

## Exact copy
**PageHeader**
- Eyebrow: `WORKSPACE`
- H1: `Team dashboard`
- Description: `<Quarter label> · <county or "All counties"> · <referral or "All referral sources">` e.g. `Jul–Sep 2026 (Q3) · All counties · All referral sources`
- Right: aggregate `FreshnessChip` (same as top bar). `Export packet` button hidden until F-403 exists.

**Filter bar:** labels `Quarter`, `County`, `Referral source`, toggle `Compare to prior quarter`; mobile button `Filters`, sheet title `Filter the dashboard`, buttons `Apply`, `Reset`.

**Metric cards** (title · value format · delta · footer)
- M1 (headline, full width): `Days from court order to first session` · median `23 days` large; stats row `25th pct 14 · 75th pct 38 · n = 142 · Still waiting 9%` · delta `↓ 4 days faster than Q2` / `↑ 3 days slower than Q2` / `No change from Q2`
- M2: `Days from application to funding decision` · median `6 days`
- M3: `Approved but never started` · `12%` · sub-line `Top reason: <non_start_reason label>` · muted `No session within 60 days of approval`
- M5: `Cost per completed episode` · `$1,840` · sub-line `Program total ÷ completed: $2,105`
- M4 (table): `Completion rate by income band` · columns `Income band` · `Completed` · `Closed` · `Rate`
- M6: `Where therapy dollars went` · `Affiliated providers 31% · Other providers 69%` · rate table columns `Provider group` · `Avg rate per hour` · `Dollars` · `Episodes`
- O1: `Outcome change` · per measure row `<Measure>` · `Mean change` · `Share improved` · `n` · direction note `Lower is better` / `Higher is better`
- Every FAS card footer (`SourceFooter`): `FAS records · <Quarter label> · n = <n> · as of <Mon YYYY>`; append `· includes hidden bands` when complementary suppression hid any row; append badge `Σ Aggregate` when aggregate submissions feed it.

**Freshness widget:** title `Public data freshness` · up to 4 sources sorted worst first, each `FreshnessChip` + source name + `Latest <vintage>` · link `See all sources` → `/data-freshness`.

**Pipeline widget:** title `Grant pipeline` · one row per stage in order `New`, `Reviewing`, `Pursuing`, `Submitted`, `Awarded`, `Declined`, `Passed` with counts as text; hand-entered foundation grants count in their stage and carry a `Manual entry` text tag (badge) wherever they're listed · `Next deadline: <title>, closes <Mon D>` · link `Open pipeline` (hidden until the route exists) · footer `Grants.gov and foundation lists · as of <Mon YYYY>`; when any manual entries are counted append `· includes <n> manual entries`.

**States**
- Empty (no FAS data in the org): `EmptyState` page-level, title `No FAS data yet` · body `Upload your case file or enter cases to see these numbers.` · action `Upload data` only if `/upload` exists. Freshness and Pipeline widgets still render.
- Filter-no-results: in each FAS card, `No cases match these filters` · button `Reset filters`.
- Metric not available yet (view missing; feature not shipped): card body `Not available yet` · muted `This number appears when <metric name> is set up.` · no value, no footer.
- Not enough data: M1/M2 with n = 0 → `No closed cases this quarter`; M4/M5 zero denominators → `Not enough closed episodes`.
- Suppressed: value replaced by `SuppressedCell` (`— n<11`, lock glyph, tooltip `Suppressed (n < 11) to protect privacy.`); complementary-hidden cells use `Hidden · protects another cell`. Rates and deltas on a suppressed count are hidden too.
- Loading: page header static; each card a skeleton matching its final size (no layout shift); shimmer off under reduced motion.
- Error (per card): inline `ErrorState` in that card: `Couldn't load this number` · `Try again` · reference id. Other cards stay usable.
- Error (whole page): `Couldn't load the dashboard` · `Something went wrong on our side. Try again.` · `Try again`.
- Partial: freshness widget with a Failed source shows `Last run failed` for that source; pipeline empty → `No opportunities in the pipeline yet.`
- Permission-denied: board → DS-04 403 card, real 403.

## Trust rules
- **n<11:** any count < 11, and any rate, median or delta built on one, renders as `SuppressedCell`; complementary suppression per F-306 (e.g. hide the 200–299% band when the 300%+ band is suppressed and a total is shown). The UI never shows a total that lets a hidden cell be worked out; totals read `includes hidden bands`.
- **County level only:** the county filter is the finest geography; no city or ZIP.
- **Dates:** quarter labels (`Jul–Sep 2026 (Q3)`) and month as-of; no exact case dates anywhere on this screen. Pipeline deadlines are public opportunity dates and may show a day.
- **Source + as-of** on every card and widget (`SourceFooter`).
- **Never colour alone:** deltas use arrows plus words (`faster`/`slower`); comparison series dashed + legend text; M6 segments directly labeled with percentages; freshness glyph + word; pipeline stages as text with counts; manual entries tagged in text (`Manual entry`).
- **M6** always shows average rate per hour per provider group next to the share.
- **DRAFT labels:** no AI output on this screen. If a future card summarizes with AI, it must carry `DraftBanner` (`AI draft — human review required`). N/A here.
- Synthetic data only in seeds/tests; FAS Evidence branding.

## Accessibility
- Each card is a `section` with an h2 title; M1 value has a text equivalent that includes unit and period (`Median 23 days from court order to first session, Q3 2026`).
- Trend lines: `aria-label` summary (`Median fell from 27 to 23 days over 4 quarters`) and a `View as table` toggle (button, `aria-expanded`) showing the quarter-by-quarter table.
- Tables: `th scope`, numeric columns right-aligned, tabular nums.
- Filters: labeled selects (label above); mobile sheet traps focus, Esc and tap outside close, focus returns to `Filters`; applying announces `Dashboard updated` via a polite live region.
- 44px targets below 1024 (filters, Apply/Reset, View as table, links, Try again). Input/select text ≥ 16px.
- axe 0 violations at 375 / 800 / 1024 / 1440, light and dark, with the filter sheet open on mobile. No horizontal scroll.

# DS-06 — County need map explorer
Source docs: `fas-screen-plan.md` §4 P1-4 (County need map / F-210/211), §1.2 nav, §3 trust patterns; `fas-product-inventory.md` F-210, F-211, screen #11; `design-system-v1.md` (`--chart-1` map ramp, legend with numeric bins); mockup `docs/design/mockups/p1-county-map.png`; feature list F-211 ("Map colored by need score"; "Clicking a county shows indicators with source and date"; test `e2e: map.spec.ts screenshot`).
**Depends on:** DS-05 (FreshnessChip states for sources), F-210 (need_score + need_score_config rows; versioned weights), and at least one public source loaded (F-202 SAHIE is live). **Budget:** ≤ 400 hand-written lines per PR (D-012); untouched generator output (shadcn add, the geometry build script's output) does not count. **Mockup:** `p1-county-map.png` (1440). The mockup's tile cartogram is superseded by real county outlines at 768 and up (see Layouts).

## Purpose and users
Show where need is highest across Utah's 29 counties, with every number traceable to a public source and date, so staff can steer outreach and cite need in grants, and board members can see the same picture read-only.

| Role | Gets | Doesn't get |
|---|---|---|
| staff | Map, table view, county panel, link to Methodology (when it exists) | — |
| admin | Same as staff; "Need-score weights" link in the panel footer only if `/admin/need-score` exists | — |
| board_viewer | Same map, table and panel, read-only, all 29 counties with FAS service counties marked | No "Add to packet" or admin links |

Public data only. No FAS case data appears on this screen in this spec.

## Scope
- Route `/need-map`, all signed-in roles (`ALL` in `RULES`; board included). Unhide nav item "County need map" for staff, admin (Workspace group) and board (board nav item 3). Breadcrumb `County need map`.
- Query params: `?view=map|table` (default `map` at ≥ 768, `table` below 768), `?county=<fips>` selects a county (shareable; back button restores it), `?layer=need|<indicator_code>` (default `need`), `?fas=1` turns on the `Show FAS counties only` filter (default off; all 29 counties shown).
- **FAS service counties:** the list comes from config/seed (`fas_service_county` fips list); synthetic in tests and previews. No FAS case data is used to derive it.
- Map colored by the **latest approved** `need_score` version (`need_score_config.approved_by IS NOT NULL`, newest `created_at`).
- County panel shows `need_score.score`, rank, and each `public_indicator` row for that county's latest vintage, each with source, vintage and MOE.
- Out of scope: county detail page `/need-map/:fips`, methodology page (F-210 owns it; link hidden until the route exists), "Add to packet", trend by vintage, weight editing.

## Layouts (signed in, inside the DS-02 shell, DS-01c `Page`)
Shell figures as DS-02 / DS-05:

| Viewport | Sidebar | h1 left | Content width |
|---|---|---|---|
| 375 | none (top bar) | **16** | **343** |
| 800 | 56 rail | **80** | **696** |
| 1024 | 256 | **288** | **704** |
| 1440 | 256 | **288** | **1120** |

**PageHeader:** eyebrow, h1, description; actions cluster right at ≥ 768, full-width below: the Map / Table toggle (shadcn `tabs`, two triggers, each ≥ 44px tall below 1024) and the `Methodology` link (hidden until `/methodology` exists).

**FAS filter:** a `Show FAS counties only` switch (shadcn `switch`, or a checkbox button) sits in the PageHeader actions after the layer select, off by default. When on, map greys non-FAS counties to `--muted` with no fill (still focusable, labeled) and the table lists only FAS counties; rank stays the statewide rank.

**Below 768 (375):** Toggle defaults to **Table**. Map view, when chosen, is a full-width **tile cartogram** (29 equal squares in a fixed Utah-shaped grid, 6 columns × 7 rows; tile ≥ 44px, so each tile is a full tap target and carries its rank as text). Tapping a county opens the county panel in a bottom `sheet` (max height 85vh, Close button 44px, focus trapped, Esc and tap outside close, focus returns to the tile). Layer select sits above the map, full width, label stacked above. Legend wraps under the map in two rows. No page horizontal scroll.

**800 (rail):** Map uses real county outlines, full content width (696), aspect ~ 4:5, height ≤ 640. County panel is a card **below** the map (not a sheet), with the selected county's name as an h2. Legend sits under the map in one row.

**1024:** `Grid` 7/5 split: map card left (≈ 400 wide), county panel right (≈ 280), sticky to the top of the viewport below the top bar. Panel lists indicators in a single column; MOE wraps under the value.

**1440:** Same 7/5 split at 1120 content (map ≈ 650, panel ≈ 450). Rank numbers print at each county's centroid (11px mono, `foreground` on light bins, `primary-foreground` on the two darkest bins) where the county's bounding box is ≥ 28px; smaller counties show the rank on hover/focus and in the panel.

**Table view (all widths):** shadcn `table` inside DS-01c `ResponsiveTable` (stacked rows below 768). Columns: County (with a `FAS county` badge for service counties) · Rank · Need score · Bin · one column per indicator in the current layer set · Status. Default sort: Rank ascending; Not published counties last. Headers are sort buttons with `aria-sort`. Row click (or Enter) selects the county and opens the panel.

**Color:**
- Map ramp: `--chart-1` at Tailwind opacity steps `/15`, `/35`, `/55`, `/75`, `/100` for bins 1–5 (no new tokens or raw values). These are placeholder bins until George sets the weights.
- County stroke `--border`; selected county 3px `--ring` outline plus a raised stroke.
- **FAS service county:** 2px solid `--foreground` outline (drawn under the selection ring), always paired with the text `FAS county` in the panel, table and legend; never colour alone.
- Mobile tile map: FAS tiles get the same 2px outline plus a small `FAS` text mark.
- Not published = `--suppressed` hatch pattern (existing) with the words in the legend and in the panel.
- Dark mode uses the dark `--chart-1` with the same steps; check 3:1 between adjacent bins' text labels, not between fills.

**Geometry:** Utah county outlines from US Census TIGER/Line cartographic boundary (public domain), simplified and projected at build time by a small script into `public/geo/utah-counties.json` (fips → SVG path). The JSON is generator output (untouched) and excluded from the line count; the script counts.

**County panel**
- Prompt before selection: `Select a county on the map or in the table.`
- Heading: `<County name> County` · badge `FAS county` for service counties
- Score line: `Rank <n> of <ranked count> · Need score <+0.00>`
- Indicator row: `<Indicator name>` · value with unit (`9.2%`, `95,000 people`) · `± <moe>` muted · footer `<source name> · <vintage> · as of <month year of last success>`
- Not-published indicator: `Not published` chip + `<source name> did not publish this for <county> in <vintage>.`
- Stale indicator: `FreshnessChip` Stale · N days beside the source line
- Panel close (sheet only): `Close`

**SourceFooter (under map card and table):** `Public sources: <comma list> · Need score version <version> · as of <latest last_success month year>`

**States**
- Empty (no approved need score): title `Need score not computed yet` · body `The map appears once an admin approves a need-score version. County indicators are still in the table.` · Table view stays usable (indicators without rank/bin). Admin action `Go to need-score weights` only if that route exists.
- Empty (no public data at all): title `No public data loaded yet` · body `County numbers appear after the first public data source finishes loading.` · no action for staff/board.
- Loading: map card = static Utah outline in `--muted` with no fills (no shimmer under reduced motion); panel = 4 skeleton indicator rows; table = 8 skeleton rows.
- Error (all data): `ErrorState` title `Couldn't load the need map` · body `Something went wrong loading county data. Try again.` · `Try again` · reference id.
- Partial (geometry failed but data loaded): map card shows `ErrorState` title `The map didn't load` · body `County data is still available in the table.` · button `Show table`. Table still renders.
- Partial (some counties Not published): hatched, labeled in legend, listed last in table with `Not published` in the Rank and Score cells. Never colored, never 0.
- Partial (a source failed its last run): its indicators show the last published vintage with `FreshnessChip` Failed beside them; if there's never been a success, `Not published`. Never show fabricated values.
- Filter on, no FAS counties configured: `No FAS counties set` · body `The FAS county list hasn't been configured yet.` · switch stays usable to turn off.
- Permission-denied: none (all roles). No-role users get the DS-04 "Account not set up" card via the existing guard.

## Trust rules
- **Source + as-of on every number:** every indicator row and the score line carry source, vintage and as-of (month year). The score line's source is `Need score version <v> · weights approved <month year>`.
- **County level only:** the finest geography is county. No points, tracts, or addresses. No FAS case locations on this screen.
- **n<11 suppression:** public indicators are not counts of FAS clients, so FAS suppression doesn't apply. If a future layer derives from FAS data, it must use `SuppressedCell` and is out of scope here. Sources' own "not published" flags (SAHIE `N/A`) show as Not published.
- **Dates:** month or year only (vintages as published; as-of as `Oct 2026`).
- **Never color alone:** FAS counties = 2px `--foreground` outline + `FAS county` text in panel, table badge and legend; numeric bin ranges in the legend; rank text on tiles (mobile) and at centroids where they fit; every county's `aria-label`; the table view with rank and bin as text; Not published uses hatch plus words.
- **DRAFT labels:** no AI output on this screen. N/A.
- FAS Evidence branding only; synthetic data in seeds and tests.

## Accessibility
- The table view is the full equivalent of the map. The toggle is a `tablist`; selection persists in the URL.
- Each county path / tile is a `button` (`role="button"` on `<path>` with `tabindex`, or an overlaid `<a>`) with `aria-label="<Name> County, rank 4 of 26, need score +1.74"` (append `, FAS county` for service counties) or `"<Name> County, not published"`. `aria-pressed="true"` on the selected county.
- Keyboard: Tab enters the map at the selected (or first by rank) county; arrow keys move to the geographic neighbor (tile grid neighbors on mobile; a precomputed neighbor map on desktop); Enter/Space selects; Esc clears selection. Focus ring 2px `--ring` visible on paths (outline via a duplicated stroke).
- Selecting a county announces the panel heading via a polite live region.
- Targets ≥ 44px below 1024 (tiles, toggle, select, Close, rows). At ≥ 1024 small counties are below 44px, which is acceptable at desktop under WCAG 2.2 target-size because the table offers an equivalent control.
- Map has `role="img"`-equivalent summary: `aria-describedby` text `Highest need: <top 3 counties>. Lowest need: <bottom 3>. <k> counties not published.`
- axe 0 violations (WCAG 2.2 A/AA) at 375 / 800 / 1024 / 1440, light and dark, map and table views, sheet open on mobile.
- Reduced motion: no animated fills or pan/zoom transitions. No pan/zoom at all in this spec.

# DS-23 — Need map: the picked county stands out, and the map follows the scroll

**Source docs:** `docs/design/specs/DS-06.md` (colour rules), `DS-20.md`, `DS-22.md`; `docs/DESIGN.md` need-map rules. **Depends on:** DS-22 (stacked on `ds-22-county-picker`, D-032).

## Purpose and users
George, after seeing one county at a time: "id like the county selected to be highlighted on the map so we know what county we are looking at, and id like the map to move up and down with the mouse as the user is scrolling." Same page for staff, admin and board viewers.

## Scope
1. Selected county: the others fade, the picked one gets a two-stroke outline.
2. From 1024 the map and its legend are one sticky block; the county panel scrolls normally (a tall panel with "All measures" open is taller than the viewport, so a sticky panel was cut off).
Nothing else changes: picker, panel, legend wording, numbers, queries, sidebar.

## Layouts
| Width | Map and legend | Panel |
|---|---|---|
| 375, 800 | stacked, not sticky (map, legend, panel) | follows the legend |
| 1024, 1440 | left 7 columns, `sticky`, `top` 4.5 rem (clears the 56 px top bar), `self-start`; map height `min(640 px, 100dvh − 19.5 rem)` | right 5 columns, scrolls normally |

19.5 rem = 72 px offset + legend (up to 126 px when it wraps at 1024) + the page's bottom space (about 113 px), so the block still fits when the page is scrolled to the end and the map does not ride up. Measured 1440x900: map 588 px; 1024x768: 456 px.

## Components (existing only)
`NeedMap` (one file), `MapHover`, `MapSelect`. No new token: `--background`, `--foreground`, existing opacity step.

## Exact copy
No new visible copy. The map's screen-reader summary gains `Selected: <County>.` when one is picked.

## States
- None selected: nothing dims, no outline.
- Selected (from the map or the menu): selected path `data-selected`, the other 28 `data-dimmed` at 55% opacity (150 ms transition, none under reduced motion); outline = 6 px `--background` stroke under a 3 px `--foreground` stroke, above the FAS outlines. Hatched counties stay hatched, only fainter; FAS outlines are not dimmed.
- `?fas=1`: the 24 non-FAS counties are already muted (`data-dim`) and are not dimmed again; only the other FAS counties dim.
- Rank numbers stay full strength; on a dimmed county they use `--foreground` (a dimmed dark fill is as light as a middle band, so white text would fail contrast).
- Loading, empty, error: unchanged.

## Trust rules
No number, label or source changed. Shape and contrast mark the pick, not colour alone (WCAG 1.4.1, 1.4.11); the hover card and the panel say the county in words.

## Accessibility
`aria-pressed`, arrow keys and the hover card unchanged. Hover card positions from `getBoundingClientRect` at hover time, so it lands correctly on a stuck map (checked after scrolling). Sticky needs no `overflow` ancestor: the window scrolls, `#main` and the card have none. Below 1024 nothing is sticky, so reflow at 320 px and 200 % zoom is unchanged. `design:accessibility-review`: focus ring unchanged, axe 0 serious/critical with a pick, light and dark.

## Decisions
- Dim with `opacity` on the path (one class, transitions cleanly, covers hatch and stroke) rather than recolouring fills.
- Map height formula reserves room for the legend and the page's bottom space so the block never rides up at the end of the page.

## Open questions
- Below 1024 the menu sits below the map, so choosing a county there means scrolling back up. The picker could also appear above the map on phones (a one-line move; needs George's call because it repeats the control).

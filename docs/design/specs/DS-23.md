## Purpose and users
Staff who type a quarter's total by hand see a Σ Aggregate badge and a list of recent totals. Neither said what "aggregate" means or where the number came from; the words existed (DS-18b) but were not wired. Three pages that read the database on every request (`/data-freshness`, `/methodology`, `/staff/packets`) showed the parent route's skeleton (or nothing) while the server worked.

| Role | Gets |
|---|---|
| staff, admin | Aggregate totals form: a plain sentence under every field; the Σ badge opens the glossary sentence on hover, focus and tap; every recent total opens one explain card (what it is, the total in words, the source) |
| staff, admin, board_viewer | `/data-freshness` and `/methodology` load into a skeleton shaped like the page |
| staff, admin | `/staff/packets` loads into a skeleton shaped like the packet |

## Exact copy
- Σ badge hint: `A total that FAS entered as a total, not built up from individual records.` (glossary `aggregate.plain`).
- Recent-total card: title `Aggregate submission`, the glossary sentence, value `<total> <metric, lower case>, <quarter in words>, <county or All counties>` (e.g. `47 families served, Jan–Mar 2026 (Q1), Salt Lake`), source `FAS aggregate total, entered by staff`.
- Period: `The quarter the total covers, like 2026-Q2. Required; Q1 is January to March and Q4 is October to December.`
- Metric: `What the total counts, such as families served or dollars paid to providers. Required.`
- Total: `The total for the quarter, as a whole number of 0 or more; for dollars paid, in dollars, like 1840.00. Required.`
- County: `The Utah county the total covers. Leave as All counties for a total across the whole organization.`
- Note: `Anything a reader needs to know about this total, up to 200 characters. Plain words, no names or client details.`
- Skeleton sentences: `Loading data freshness. …`, `Loading the need score methodology. …`, `Loading the evidence packet. The page appears in a moment.`

## States
Unchanged: empty list (`No aggregate totals yet.`), field errors, alert count, saved line. A total saved this session joins the list and the layer at once (client state). The skeletons are the new loading states.

## Trust rules
The card shows only stored fields (period, metric, value, county) and a fixed source sentence; no as-of date is invented. No number is added.

## Accessibility
The Σ trigger is a `button` named `Aggregate submission` (label in name). Totals are `tabIndex=0` targets; Enter pins the card as a `dialog`, Escape closes and returns focus, arrow keys walk the totals, a polite live region reads the same words. Hint sentences are listed in `aria-describedby`. Skeletons are `role="status"` with one sr-only sentence, bars `aria-hidden`, no pulse under reduced motion. axe 0 serious/critical asserted with the card open and on the existing 375/1024 run.

## Decisions
1. Row badges in the recent list stay plain labels: ten extra tab stops would say the same sentence the total beside them already opens (the card's title and first line are the badge's words). The notice badge carries the `Hint`.
2. E2e lives in `tests/e2e/aggregate.spec.ts` (it owns the aggregate helpers) rather than `entry-forms.spec.ts`.
3. `ROUTES` grows by a `push` on its own line so it merges cleanly with #287, which edits the array line.
